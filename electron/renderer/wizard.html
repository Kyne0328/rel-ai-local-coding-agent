Rel.AI MCP Launcher

Connect ChatGPT to your local files through a secure ngrok tunnel. Setup takes about 2 minutes — you'll need an ngrok account with a static domain.

Local server port

The port the MCP server listens on. Leave as 3333 unless another app is already using it.

Dashboard token

This token protects your local dashboard. Copy it now and save it somewhere safe — you'll need it to log in to the dashboard later.

ngrok static domain

Find your static domain at ngrok.com → Dashboard → Domains. Paste it below without the https:// prefix.

Command that will run: ngrok http --url=<domain> 3333 --log=stdout

All set!

After launch, copy the MCP URL and add it in ChatGPT as a connector with No Authentication. Treat the URL like a password.

Settings are saved — this wizard won't appear again on next launch.
