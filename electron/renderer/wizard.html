Connect this computer to ChatGPT

Rel.AI keeps repositories and tool execution on this computer. OpenAI Secure MCP Tunnel gives ChatGPT a private route to the local MCP service.

Get the two OpenAI values first You only need a Tunnel ID and a restricted runtime API key for this computer.
2 values
  1. Create or select a Secure MCP Tunnel OpenAI Platform → Organization settings → Tunnels. Copy the ID that starts with tunnel_.
    https://platform.openai.com/settings/organization/tunnels
  2. Create a restricted runtime API key OpenAI Platform → Organization settings → API Keys. Give the key Tunnel permissions for Read and Use, then copy it while it is visible.
    https://platform.openai.com/settings/organization/api-keys

Use the tunnel assigned to this computer. The ID begins with tunnel_.

This key runs the OpenAI tunnel client. Rel.AI encrypts it with the operating system credential store and never shows the saved value again.
