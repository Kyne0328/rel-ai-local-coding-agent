# Rel.AI Skill Provenance

All skills in this package are first-party Rel.AI content maintained in this repository.

The modular architecture was informed by general progressive-disclosure and single-responsibility patterns used by agent workflow projects, including `obra/superpowers` revision `44c9b2d6e889982ac18c27d05a19fefe335194e1`. No third-party skill text, executable hook, update mechanism, telemetry behavior, or remote-download script was copied or vendored.

Skill content is versioned with the plugin. Runtime downloads, silent updates, and executable skill scripts are not permitted in the initial skill set. MCP server policy, workspace ownership, approvals, command bounds, and destructive-operation safeguards remain authoritative.
